# Kyle Stein Research Website

Static academic research website designed for GitHub Pages.

## Publish at `argonauts18.github.io`

1. Create a GitHub repository named exactly `argonauts18.github.io`.
2. Upload the contents of this folder to the repository root.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, `main`, `/ (root)` if Pages is not already enabled.
5. Visit `https://argonauts18.github.io`.
